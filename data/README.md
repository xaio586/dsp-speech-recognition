# 实验数据目录

本项目当前保存5位组员的原始录音和统一格式后的数据。每人23条：数字0—9各录两遍（20条），姓名录三遍（3条），共115条原始录音和115条处理后音频。

## 目录

- `raw/spk01` 至 `raw/spk05`：手机录制的原始 M4A 文件，保留录音内容，只统一了文件名和目录结构。
- `processed/spk01` 至 `processed/spk05`：转换后的 WAV 文件，16 kHz、单声道、PCM16。
- `processed/metadata.csv`：每条处理后音频的说话人代号、类别、录音轮次、原始格式、采样率和质量检查信息。
- `dataset_summary.csv`：按成员汇总的数据数量与状态。

数字文件名形如 `spk01_digit_0_take01.m4a`；姓名文件名形如 `spk01_name_take01.m4a`。处理后的 WAV 使用相同命名规则。

## 公开说明

这些录音由小组成员提供，五位录音者已同意将原始录音和处理后数据放入公开 Gitee 仓库。录音中包含本人声音，姓名录音还会直接说出姓名。
