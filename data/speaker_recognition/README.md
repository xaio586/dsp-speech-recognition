# 说话人识别数据

五位组员的说话人模型由“定长特征向量 + RBF SVM”构成：每条训练录音提取 13 维 MFCC 及一阶/二阶差分的逐系数均值与标准差（78 维），加逐帧 12 阶 LPC 系数的均值与标准差（24 维），共 102 维；服务启动时用这些向量拟合 `StandardScaler + SVC(RBF)`。这是监督分类方案，不再做 MFCC 序列的 DTW 模板匹配。

网站部署只需 `metadata.csv` 与 `svm_features.npz`（40 条训练录音经声道增强后的 160 条 102 维向量，由 `scripts/build_svm_features.py` 从训练 WAV 生成），不必将每条原始声音放进代码仓库。旧的 `templates.npz`（40 条训练 MFCC 序列）保留作为无 LPC 特征时的回退来源。完整原始 M4A 和统一 WAV 数据包在项目负责人本地单独保存。

`metadata.csv` 标出姓名、说话人编号和训练/测试用途；完整评测需要把统一数据包展开到本目录，以提供 `wav/` 文件。当前数据量为 40 条训练录音（每人 4 句 × 2 遍）、27 条测试录音（7 条个人自由稿 + 20 条共同短句）。WAV 参数为 16 kHz、单声道、PCM16。
