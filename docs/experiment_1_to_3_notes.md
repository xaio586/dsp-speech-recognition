# 实验1—3技术整理

## 实验1：语音时域分析

主流程为：读取语音 → 去直流/归一化 → 分帧 → 加窗 → 短时能量与过零率 → 双门限端点检测。

- 预加重：`y[n] = x[n] - a·x[n-1]`，后续MFCC默认 `a=0.97`。
- 分帧：参数统一放在 `src/dsp_speech/config.py`；默认帧长25 ms、帧移10 ms；16 kHz下分别为400点和160点。末尾不足一帧时补零保留。
- Hamming窗：`w[n] = 0.54 - 0.46 cos(2πn/(N-1))`。
- Hann窗：`w[n] = 0.5(1 - cos(2πn/(N-1)))`。
- 短时能量：`E[k] = Σ x_k²[n]`。
- 短时平均幅度：`M[k] = Σ |x_k[n]|`。
- 短时过零率：`Z[k] = 1/(2N) Σ |sgn(x_k[n])-sgn(x_k[n-1])|`。

当前代码先用自适应高能量阈值定位语音核心，再用低能量阈值与连续过零率条件向两侧扩展，合并短暂停顿并过滤过短脉冲。端点以原始采样点的左闭右开区间返回。调用 `analyze_time_domain` 可一次得到能量、短时幅度、过零率和端点结果。

## 实验2：MFCC

流程为：预加重 → 分帧/Hamming窗 → FFT功率谱 → Mel三角滤波器组 → 对数 → DCT。接口 `extract_mfcc` 返回 `(帧数, 13)` 的 `float32` 矩阵，便于直接进入DTW。

## 实验3：DTW模板匹配

每个数字保留一个或多个MFCC模板。待识别语音提取MFCC后，与各模板计算动态时间规整距离，取最小距离对应数字。接口如下：

```python
features = extract_mfcc(samples, sample_rate)
label, distance = recognize_digit(features, templates)
```

## 第4周建议评测方法

- 核心指标：数字分类准确率、错误率、10×10混淆矩阵。
- 划分原则：同一说话人的同一次录音不能同时出现在模板与测试中。
- 两种实验：第二遍作测试的“已见说话人”实验；按人留一的“未见说话人”实验。
- 同时记录端点检测失败数、单条推理时间和实时演示是否在录音结束后1秒内给出结果。
