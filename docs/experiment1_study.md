# 实验一调参消融与比较实验

## 实验目的

本实验在仓库现有的时域分析和双门限端点检测程序上，观察阈值参数、端点检测步骤和窗函数变化后，程序输出会有怎样的变化。数据使用 `data/processed` 中100条数字录音。所有方案读取同一批文件，除正在比较的变量外，其余参数保持 `DEFAULT_CONFIG` 不变。

## 实验设置

基准参数为16 kHz采样率、25 ms帧长、10 ms帧移、Hamming窗、高能量比例0.10、低能量比例0.025、最短语音50 ms、静音合并120 ms、连续过零率扩展3帧。脚本 `scripts/experiment1_study.py` 执行三类实验：

1. 调参实验：高能量比例取0.05、0.10、0.20，低能量比例取0.015、0.025、0.05，组成3×3参数网格，共9组。
2. 消融实验：分别关闭过零率扩展、取消高低门限差异、取消最短语音长度筛选，观察输出区间变化。
3. 比较实验：将端点检测的窗函数分别设为矩形窗、Hamming窗和Hann窗。

记录指标为非空端点输出比例、检测区间平均时长、相对基准的平均端点变化量、端点变化量95分位数和单条录音平均运行时间。端点变化量取起点和终点绝对变化的平均，单位为毫秒。

## 实验结果

基准程序对100条文件均返回非空区间，平均区间时长595.5 ms，中位数475.0 ms，平均运行时间约3.2 ms/条。这里的“非空端点输出比例”只表示程序返回了 `start < end`，不能当作端点检测准确率，因为本批录音没有逐采样点人工标注的真实起止位置。

调参网格中9组均返回非空区间。高能量比例0.10、低能量比例0.025就是当前基准。提高低能量比例到0.05时，平均区间时长从595.5 ms降到574.1 ms，但平均端点变化达到12.2 ms，95分位变化约40.2 ms。将高能量比例增至0.20、低能量比例设为0.05时，平均时长进一步降至565.5 ms，平均边界变化为16.7 ms。仅凭区间更短不能判断更准确，是否截断尾音还需结合人工标注和波形抽查。

消融实验中，关闭过零率扩展后平均区间时长降到461.2 ms，平均端点变化为67.2 ms，95分位变化约170.8 ms，说明该步骤会明显影响边界延伸。取消高低门限差异后平均时长为554.0 ms，平均边界变化23.7 ms，95分位变化约80.2 ms。去掉最短语音长度筛选后，平均时长为600.9 ms，平均边界变化2.7 ms；在当前数据中影响较小，但仍可能影响短促噪声或异常片段的保留。

窗函数比较中，三种窗均得到非空区间。相对Hamming基准，矩形窗的平均边界变化为9.7 ms，95分位约30.2 ms；Hann窗的平均变化为0.8 ms，95分位为5.0 ms。当前数据上Hann与Hamming输出更接近，矩形窗改变较明显。该结果描述的是区间敏感程度，不足以证明某种窗函数的检测准确率更高。

基准区间时长的95分位为1388 ms，最长达到4685 ms；7条录音的输出区间超过1200 ms。结合此前5条端点抽查中发现的尾部突发声、分段合并和背景噪声等情况，100%非空输出并不表示100条均切分正确。建议优先复核长区间录音，并给一批代表性样本补充人工起止标注，再计算边界绝对误差、漏检率和误检时长。

## 输出文件

- `outputs/experiment1_study/summary_metrics.csv`：每组实验的汇总指标。
- `outputs/experiment1_study/per_recording_metrics.csv`：每条录音在每种设置下的端点、区间时长和边界变化。
- `outputs/experiment1_study/study_manifest.json`：参数、样本量和指标解释。
- `outputs/experiment1_study/threshold_tuning.png`：阈值网格结果图。
- `outputs/experiment1_study/ablation_comparison.png`：消融结果图。
- `outputs/experiment1_study/window_comparison.png`：窗函数比较图。

## 复现

在仓库根目录运行：

```powershell
python scripts\experiment1_study.py
python -m pytest -q -p no:cacheprovider --basetemp=.codex-weekly-build/pytest-tmp
```

本次脚本处理100条数字录音；仓库现有自动测试22项通过。所有输出指标都应结合上述人工标注缺失的限制解释。
