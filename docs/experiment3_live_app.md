# 实验三：MFCC + DTW 实时数字识别

## 功能

- 页面直接调用电脑麦克风录音；不上传音频文件，也不连接云端识别服务。
- Python 本地服务把音频统一到16 kHz，进行端点检测、MFCC提取和DTW模板匹配。
- 页面显示识别数字、有效语音时长和三个最接近类别的距离。
- 模板从 `data/processed/metadata.csv` 读取，只使用0—9数字WAV；姓名录音不会作为数字模板。
- 另有两折轮换评测脚本，take01训练/take02测试，再交换训练和测试轮次，输出预测明细和混淆矩阵。

## 页面设计来源

`src/dsp_speech/web/design_sources/` 保存你提供的首页、说话人页、最新数字识别页和训练文档页原始源码。页面源文件保持不变；`integration.js` 单独负责首页跳转、数字页的麦克风选择/录音，以及调用本地识别接口。当前只有“数字识别”页连接了 MFCC+DTW 识别；“说话人识别”和“训练文档”页按你给的源码作为展示页面。

## 启动实时程序

在仓库根目录运行：

```powershell
.\.venv\Scripts\python.exe scripts\run_experiment3.py
```

浏览器打开 `http://127.0.0.1:8765`。如果使用耳机麦克风，先点击“授权 / 刷新设备”，允许浏览器调用麦克风，再从“输入设备”选择耳机麦克风。点击“开始录音”，对麦克风说一个0—9数字，再点击“停止并识别”。录音最长8秒，也可以提前停止。按终端里的 `Ctrl+C` 关闭服务。

若提示模板缺失，先检查 `data/processed/metadata.csv` 中的 `relative_path` 是否对应已生成的WAV文件。若浏览器没有麦克风权限，检查浏览器地址栏的网站权限并使用 Edge 或 Chrome。

## 离线评测

```powershell
.\.venv\Scripts\python.exe scripts\evaluate_experiment3.py
```

结果写入 `outputs/experiment3/`：`predictions.csv` 为逐条预测，`confusion_matrix.csv` 为10×10混淆矩阵，`summary.json` 记录总准确率和两折结果。该划分按同一人的两次录音分开训练与测试，衡量的是已收录说话人的跨轮次识别；它不能直接代表未录入模板的新说话人效果。

## 识别流程

```text
浏览器麦克风录音
→ 本机HTTP接口接收单声道浮点音频
→ 重采样至16 kHz、去直流、归一化、端点截取
→ 提取13维MFCC
→ 与0—9模板逐类计算DTW距离
→ 输出最小距离对应的数字
```

服务只绑定 `127.0.0.1`，音频不会被保存到磁盘或发送到网络。识别范围由当前小组采集的数字模板决定；正式课堂演示前仍需在实际麦克风和教室环境下试说并调整录音习惯。
