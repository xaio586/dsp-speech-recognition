METHOD / PIPELINEMFCC + DTW

从声音到数字

网页只负责采集现场语音，识别计算由本机 Python 程序完成。

01 / INPUT
麦克风录音
说话时采集单声道音频；停止后将录音交给本机识别服务。
02 / PREPROCESS
统一采样与端点
重采样到16 kHz，去除直流分量并检测语音区间，减少前后静音影响。
03 / FEATURE
提取 MFCC
分帧、加窗、频谱变换和 Mel 滤波后，得到每帧13维 MFCC 特征。
04 / CLASSIFY
DTW 模板匹配
把输入特征与0—9模板逐类比较，取最小归一化 DTW 距离对应的数字。
DATA / TEMPLATE BANKPROCESSED WAV

数字模板

页面启动时从仓库的 data/processed 读取模板；姓名录音不参与数字分类。

SOURCE
组内数字录音
以 metadata.csv 中标记为0—9的 WAV 记录建立模板。当前程序以小组采集者声音作为模板范围。
LIMITATION
识别范围
识别采用孤立数字模板匹配。距离较大时仍会给出最接近类别，实际效果需要结合麦克风和课堂环境验证。
