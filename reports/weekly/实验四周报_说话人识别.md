# 实验四阶段周报：说话人识别

**项目阶段：** 实验四——说话人识别与验证  
**报告日期：** 2026-11-06（深度声纹模型上线后更新）  
**报告人：** 肖绚聍

## 本周工作计划

在现有实时语音识别网站中接入说话人识别模块。按实验书要求，识别结果应尽量不依赖说话内容：第一版曾用 MFCC+DTW 模板距离，但该方案本质上仍是把测试语音和固定句子模板做时序匹配，不符合“任意内容说话人识别”的目标。本周先将算法替换为**定长说话人特征向量 + RBF 核 SVM 监督分类器**，随后在补充自由朗读数据的基础上，上线**预训练 ECAPA-TDNN 深度声纹嵌入 + 余弦质心**方案，重新评测并更新网站展示。

## 本周完成情况

1. **数据整理与划分**  
   汇总五位组员提交的录音，保留手机原始 M4A 副本，并统一生成 16 kHz、单声道、PCM16 WAV。初始每人有 8 条训练录音（4 个句子 × 2 遍）；测试录音共 27 条，分为个人自由稿（7 条）和共同短句（20 条）。靳博文补交的 14 条录音已纳入数据集，其中 8 条用于训练、6 条用于测试。
   为提升内容无关性，五位组员随后各补录约 5 分钟自由朗读，经能量语音活动检测切成 3–8 秒语段（`scripts/ingest_free_speech.py`），新增 203 条训练段（prompt_id=free01），训练录音合计 **243 条**。真实姓名、说话人编号、训练/测试用途和原始文件信息已写入 `metadata.csv`。组长另有课堂外雅思口语录音（英语随机内容）切成 86 段，仅作额外测试，不进训练集。

2. **算法一（课程自研管线）：MFCC/LPC 统计特征 + RBF SVM**  
   每条录音先做重采样、去直流、端点检测（与实验三共用基础预处理），然后提取：
   - 13 维 MFCC 及其一阶、二阶差分，对每个系数取均值和标准差，共 78 维；
   - 逐帧 12 阶 LPC 系数（自相关法 + Levinson-Durbin 递推）的均值和标准差，共 24 维；
   - 合计 **102 维定长特征向量**，只描述嗓音统计特性，不保留语句时序。
   分类器为 `StandardScaler + SVC(RBF)`；训练侧做声道增强（每条录音生成 3 个声道变体：电话带通+8 kHz 往返、6 kHz 低通、20 dB 白噪声），超参按原始录音分组交叉验证选定 C=10、γ=scale（增强副本同组，防止泄漏）。该方案完全由本课程实验内容实现，作为对照系统保留。

3. **算法二（部署方案）：ECAPA-TDNN 深度声纹嵌入 + 余弦质心**  
   自由稿误判和现场蓝牙测试说明统计特征对内容与声道仍不够稳健，因此上线方案改为预训练深度声纹模型：SpeechBrain `spkrec-ecapa-voxceleb`（VoxCeleb 上训练的 ECAPA-TDNN）提取 192 维说话人嵌入，每位组员的全部训练录音嵌入取均值并 L2 归一化作为注册质心，识别时计算余弦相似度取最大者；softmax(相似度×10) 作为置信度，低于 0.55 标记低置信度。模型以 ONNX（fp32）导出，线上服务用 onnxruntime 推理，无需 PyTorch，满足托管平台的内存约束；ONNX 与 PyTorch 嵌入逐条核对余弦相似度均为 1.0。质心可由 `scripts/build_ecapa_centroids.py` 纯 onnxruntime 重建，重建结果与线上质心逐维一致。

4. **三组测试对比（留出测试 27 条全部未见于训练）**  

   | 测试组 | MFCC/LPC + RBF SVM | ECAPA-TDNN + 余弦质心 |
   |---|---|---|
   | 干净声道 | 26/27（96.3%） | **27/27（100%）** |
   | 蓝牙/电话声道模拟 | 25/27（92.6%） | **27/27（100%）** |
   | 组长雅思录音 86 段（跨语言、随机内容） | 65/82 = 79.3%（另 4 段端点检测拒绝） | **86/86（100%）** |

   SVM 干净声道的唯一误判是靳博文一条 45 秒自由稿被判为李欣彤；ECAPA 在包括该条在内的全部样本上正确。雅思录音组是最接近“任意内容”的检验（英语、课堂外设备与环境），ECAPA 在该组全部正确，说明嵌入方案的内容与语言无关性明显优于统计特征方案。评估脚本分别为 `scripts/evaluate_speaker_svm.py` 与 `scripts/evaluate_speaker_ecapa.py`，结果写入 `outputs/experiment4_speaker_svm/` 与 `outputs/experiment4_speaker_ecapa/`。

5. **低置信度提示与页面更新**  
   最高置信度低于 0.55 时接口返回 `low_confidence`，页面明确提示“置信度较低，可能不在这 5 位组员内，结果仅供参考”。桌面与手机页面的结果区为各说话人的相似度百分比条形图，页面说明文案已更新为深度声纹方案，麦克风、实时波形和整体设计保持不变。健康接口 `/health` 报告当前算法（ECAPA-TDNN embeddings + cosine centroids (ONNX)）与说话人数。

6. **测试与本地核验**  
   `pytest` 全部 27 项通过（含新增的 ECAPA 加载与留出录音识别测试，ONNX 文件缺失时自动跳过）；本地启动服务后 `/health` 正常，用真实测试录音 POST `/speaker/recognize` 均返回正确说话人与置信度。

## 遇到的问题

1. 系统仍是五位已登记成员的闭集识别；虽然加入了低置信度提示，但不能保证把组外说话人可靠判为“未知”，阈值 0.55 只是经验值。
2. 统计特征 + SVM 方案对训练分布外的内容仍敏感：雅思录音组只有 79.3%，且个别增强变体端点检测失败被跳过；这一局限由深度声纹嵌入方案解决。
3. 首次上线后蓝牙耳机现场测试曾全部倒向同一组员，复盘确认是声道偏移，已通过训练侧声道增强（SVM）和预训练模型本身的信道鲁棒性（ECAPA）分别修复；两类修复都以蓝牙声道模拟测试验证。
4. 实时环境的麦克风距离、设备和背景噪声可能影响结果；离线测试准确率不能直接代表现场表现。
